Why ZipClick isn't code-signed

Windows shows a "Windows protected your PC" warning the first time you run ZipClick because the program isn't code-signed. A signature tells Windows who made a program; without one, Windows can only say it doesn't know.

Certificates for signing cost money every year. The SignPath Foundation gives them to open source projects for free, but only to projects that already have a following. ZipClick applied in October 2026 and was told to come back once more people use it, which is fair. It will apply again then.

A certificate of my own costs about €60 a year. If people use ZipClick and want signed releases, I'll buy one: open an issue or star the repository to say so.

Until then, every release since 0.4.1 is built by GitHub Actions from the public source code, in the open, rather than on someone's own computer.

Privacy

ZipClick has no network code at all and sends nothing anywhere. It reads the archive you open and writes the extracted files next to it.
