Code signing policy

Status: pending. ZipClick has applied to the SignPath Foundation's free code signing program. Until the application is approved, releases are not signed yet, and this policy describes how they will be signed.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Every release will be built by GitHub Actions from the tagged source code in the public repository, and only signed after I approve that release in SignPath. Nothing built on anyone's own computer gets signed.

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

ZipClick has no network code at all. It reads the archive you open and writes the extracted files next to it.
