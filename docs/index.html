ZipClick

Double-click a zip file on Windows and get the files, like on a Mac.

The files appear next to the zip. It works the same for .rar, .7z and .tar.gz files, and asks for the password when there is one.

Download ZipClick for Windows 10 and 11

Version 0.4.0, 7.3 MB, free. On a Snapdragon (ARM) laptop, get the ARM64 version.

How to install

  1. Download ZipClick.exe and open it.
  2. Windows will probably show a blue "Windows protected your PC" box. That's because I haven't paid for a code-signing certificate yet, not because something is wrong. Click More info, then Run anyway.
  3. ZipClick asks if you want zip files to work this way. Click Yes.
  4. Windows Settings opens on ZipClick's page. Click the box under .zip, choose ZipClick, then Set default. Windows makes you do this step yourself, because programs aren't allowed to.

For .rar and .7z, do the same on that page, or wait until you open one and Windows asks: pick ZipClick, then Always. You don't need admin rights or a restart.

Questions

Where do the files go?
Next to the zip. If there are several loose files, they go into a new folder named after the zip. Nothing is ever replaced: if "Photos" already exists, you get "Photos 2".
Can I still look inside a zip without extracting it?
Yes. Right-click it, choose Open with, then File Explorer.
Is it slower than 7-Zip?
For very large .7z and .rar files, yes. A 1 GB .7z takes about 20 seconds instead of 6.
Does it connect to the internet?
No. It has no network code, and it only writes in the folder where your archive is.
How do I remove it?
Settings > Apps > Installed apps, find ZipClick, then Uninstall.
