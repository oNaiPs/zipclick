ZipClick

Double-click a zip file on Windows and get the files, like on a Mac.

It also opens .rar, .7z and .tar.gz files, and asks for the password if there is one.

Download ZipClick for Windows 10 and 11

Version 0.4.0, 7.3 MB, free. On a Snapdragon (ARM) laptop, get the ARM64 version.

How to install

  1. Download ZipClick.exe and open it.
  2. Windows will probably show a blue "Windows protected your PC" box. That's because I haven't paid for a code-signing certificate yet, not because something is wrong. Click More info, then Run anyway.
  3. Click Yes when ZipClick asks.
  4. Windows Settings opens. Under .zip, choose ZipClick and click Set default. Windows doesn't let programs do this part for you.

For .rar and .7z files, do the same on that page. Or skip it: the first time you open one, Windows asks which app to use. Pick ZipClick, then Always.

Questions

Where do the files go?
In the same folder as the zip. If there are many files, they go into a new folder with the zip's name. Nothing gets overwritten.
Can I still look inside a zip without extracting it?
Yes. Right-click it, choose Open with, then File Explorer.
Does it go online?
No, never.
How do I remove it?
Go to Settings > Apps > Installed apps and uninstall ZipClick.
